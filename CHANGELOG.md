# Changelog

## v1.0.0 (2026-07-12)

🎉 **Initial Release**

### Features
- 📷 Smart document scanning with edge detection & perspective crop
- 🔤 Arabic OCR (printed text) using Tesseract 5.x
- 📝 RTL text output with proper Arabic script display
- 📋 Copy, share, and export extracted text
- 💾 Local document storage (100% offline)
- 📄 PDF export
- 🌐 Multi-language UI: English, Deutsch, العربية
- 🎨 Material 3 theme (light + dark)
- 🔒 Privacy-first: no accounts, no cloud, no tracking

### Known Limitations
- Handwriting recognition planned for v1.1
- Tashkeel preservation in early research phase
- Edge detection only on Android (web uses manual crop)
